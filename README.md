## <img src="https://media.giphy.com/media/WFZvB7VIXBgiz3oDXE/giphy.gif" width="26"/> About Me

I'm a final-year B.Tech Information Technology student building full-stack products on the MERN stack — from REST APIs and database schemas to the interfaces people actually use. Lately I've been layering the Gemini API into that stack to build tools that reason over data instead of just displaying it.

Alongside coursework, I split my time between shipping side projects (like a placement-prep tracker and an AI-powered news aggregator), solving DSA problems, and coordinating academic and cultural events at JECRC. I care about clean, readable code and I'm currently deep in placement prep, aiming to land a full-stack SDE role.

<h3>🎯 Prep Pilot — Placement Preparation Tracker &nbsp; <img src="https://raw.githubusercontent.com/karan-21-web/karan-21-web/main/live-badge.svg" width="60" valign="middle" /></h3>

**Problem:** Placement prep is scattered across spreadsheets, sticky notes, and a dozen job portals — with no single place to track DSA progress, resumes, and company applications together.

**Solution:** A full-stack MERN application that brings DSA tracking, resume management, and company application tracking into one dashboard, with an analytics view to visualize progress.

**Architecture:** React frontend, REST APIs built with Node.js and Express, MongoDB Atlas for data, JWT + Firebase Google Sign-In for auth, deployed across Vercel and Render.

<h3>📰 NewsHub AI — AI-Integrated News Platform &nbsp; <img src="https://raw.githubusercontent.com/karan-21-web/karan-21-web/main/live-badge.svg" width="60" valign="middle" /></h3>

**Problem:** Staying on top of news usually means jumping between apps and sites, with no easy way to filter by city or category in one place.

**Solution:** A real-time news aggregator that pulls from external news APIs into a single platform, with city-based search and category filtering to make discovery faster.

**Architecture:** A responsive frontend built with HTML, CSS &amp; JavaScript, integrating third-party news APIs directly on the client, with dark/light mode for accessibility.
